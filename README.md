# CampDash
A Chrome new tab page that enables the ability to do anything, anywhere
## Features
- Astonishing stills to see depending on the time of day - it's different on every new tab
- A clock - easily see the time
- A focus of the day - type something to set it as your focus for the day
- A nice greeting - get a warm welcome on the time of day
- An inspiring quote - receive a random quote and view the author
- A quick search bar
- The weather - see the temp, the forecast for your city
- Settings - customize camp-dash and choose what's perfect for you
